# Агент или сервис для формирования UI/UX

Статус: заготовка для исследования. Дата: 2026-09-10. Релиз не назначен.

## Намерение

Изучить дополнительного агента или сервис, который помогает формировать UI/UX при работе над задачами.

## Что предстоит определить

- Входные материалы: требования, скриншоты, референсы, существующий интерфейс.
- Результат работы: сценарии, макеты, спецификация или реализация интерфейса.
- Варианты инструментов и формат подключения: роль агента, внешний сервис или плагин.
- Место в workflow, передача результата исполнителю и проверка качества.
