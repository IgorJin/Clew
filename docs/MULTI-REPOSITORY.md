# Мультирепозиторность

Статус: заготовка для проектирования. Дата: 2026-09-10. Релиз не назначен.

## Намерение

Поддержать работу над связанными изменениями в нескольких репозиториях.

## Что уже зафиксировано

[Vision](../VISION.md) описывает cross-repository Tasks и Repository Graph. [CLEW-095](../tasks/CLEW-095.md) ограничивает текущий Project одним локальным Git-репозиторием и оставляет multi-repository Projects/Tasks за рамками своего релиза.

## Что предстоит определить

- Связи Project, Repository и Task: несколько репозиториев в проекте или координация нескольких проектов.
- Поиск связей и передача контекста между репозиториями.
- Workspaces/worktrees, зависимости исполнения и совместные проверки.
- Финализация изменений, частичный успех и восстановление после ошибок.
- Связь с [эпиками](./EPICS.md) и первый поддерживаемый сценарий.
